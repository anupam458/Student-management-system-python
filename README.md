# 🎓 Student Management System (Python)

A simple **console-based Student Management System** built using Python.
This project is created to practice **Object-Oriented Programming** and
basic CRUD operations.

---

## 📌 Features

- ➕ Add student details (Roll No, Name, Marks)
- 📄 View all students
- 🔍 Search student by roll number
- ✏️ Update student details
- ❌ Delete student records
- 💾 Save data to a open file

---

## 🛠️ Concepts Used

- Python Classes & Objects
- Lists
- Loops and Conditional Statements
- File Handling
- Basic problem-solving logic
